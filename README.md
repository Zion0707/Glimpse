# Glimpse

Windows Electron 图片预览应用。所有图片都在本机读取，不上传网络。

## 界面预览

![Glimpse 最新桌面界面](docs/ui-preview.png)

采用可拖动调宽的侧边栏浏览图片，移除重复的底部胶片区与顶部品牌区，为图片留出更多空间。底部状态栏字体为 10px。

## 开发

安装 Node.js 22 或更高版本，然后执行：

```powershell
npm install
npm start
```

## 打包 Windows 应用

```powershell
npm run dist
```

安装包和免安装可执行文件输出到 `release/`。安装版支持注册常见图片文件关联。Electron 自带 Chromium，因此安装体积通常数十到上百 MB；这里的轻量化侧重无框架、无服务端和较少运行依赖。

## 功能

- 关闭窗口时可选择最小化到系统托盘、直接退出或取消。点击托盘图标恢复窗口，托盘右键菜单也可直接退出。

- 打开图片或文件夹、文件拖放、同目录浏览、缩略图、文件名搜索及排序。
- 拖动侧边栏右边缘调整宽度；也可聚焦分隔条后按左右方向键调整。
- 鼠标悬停或键盘聚焦侧边栏图片时显示删除按钮，点击后移至 Windows 回收站，可从系统回收站恢复。删除当前图片后自动显示相邻图片，删除最后一张后返回空白状态。
- 滚轮缩放、拖动平移、适应窗口、原始尺寸、旋转、水平翻转、背景切换和全屏。
- 显示图片尺寸、文件大小、格式和修改日期。
- 支持 PNG、JPEG、WebP、GIF、BMP、SVG、AVIF、ICO；具体解码能力取决于 Chromium。暂不支持 RAW、HEIC、TIFF。
- Ctrl+O 打开图片，Ctrl+Shift+O 打开文件夹；方向键切换，0 适应窗口，1 原始尺寸，R 旋转，H 翻转，F 全屏。

安全设置包括隔离的 preload、禁用 Node 集成、渲染进程沙箱，以及仅允许访问用户已打开目录图片的自定义协议。
